P05 - FAVOURITES LIST
Name: MITHRA V
Register Number: 7376251CS287

HOW TO RUN
Keep favourites.py and faves.txt in the same folder.
Run: python3 favourites.py

FEATURES
- Add movies, songs, books and games.
- Prevent duplicate titles of the same type, ignoring case.
- Search part of a title and filter by type.
- Show top five by rating; newer year wins rating ties.
- Show item count and average rating for each type.
- Edit rating and delete a favourite.
- Save and load data from a text file.
- Handle a missing data file and invalid input.

BONUS FEATURES
None.
